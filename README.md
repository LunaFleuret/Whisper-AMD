# Whisper-AMD

AMD Radeon製GPU (Vulkan) 向けに最適化されたWhisper 文字起こし環境です。
whisper.cpp の Vulkan バックエンドをベースに、**無音点検出による2分割並列処理** と **FFmpeg 音響最適化（小声強化・反響/ノイズ低減）** を統合し、Windows 環境において極めて高い精度かつ高速に処理出来ます。

> **実際の処理速度**
> **Rx9060xtで1時間の音声をわずか 1分で文字起こし出来ます（約 50〜66 倍速）**

※検証環境: AMD Radeon RX 9060 XT (16GB) / Intel Core i7-11700 / Re-BAR 有効 / モデル: `large-v3-turbo`

## 主な特徴

- **AMD Radeon 最適化 (Vulkan)**:
  - NVIDIA CUDA や ROCm 等のセットアップを必要とせず、Vulkan 経由で Radeon GPU（RX 6000 / 7000 / 9000 シリーズ等）の演算能力を最大限に活用します。
  - Resizable BAR (Smart Access Memory) 有効環境で極めて高いスループットを発揮します。
  - Whisperの仕様上Resizable BARがオンになっていないと速度低下が目立ちます。
- **2分割並列処理 (Smart Silence Splitting)**:
  - 音声の中間点付近にある「無音区間（息継ぎ等）」を自動検出し、2つのプロセスで並列推論を実行します。
  - 単一処理比で約30〜35%の速度向上になります。
- **音響最適化フィルターチェーン (ワンパス適用)**:
  - 音声抽出時にffmpegで以下のフィルターを同時に適用し、初期認識精度を高めます↓↓↓
    - `highpass=80Hz`: 空調・プロジェクター・マイク吹かれ等の低周波ノイズを遮断。
    - `lowpass=7500Hz`: 講義室・大部屋特有の高域反射音（キンキンした残響）をカット。
    - `afftdn`: 定常的な背景ノイズをFFT解析で抑制。
    - `dynaudnorm`: 動的音量平均化。小声・つぶやき・マイクから離れた音声を最大+25dBまで自然にブーストし、大声は歪まないよう抑制。
- **右クリックメニュー連携**:
  - 音声・動画ファイルやフォルダを右クリックして「Whisperで文字起こし」を選択するだけで即座に実行可能です。
- **英語専用モード**:
  - 英語音声に最適化したパラメータ（エントロピー閾値調整等）で処理するスクリプトを `English/` に同梱しています。

## 必要要件

- **OS**: Windows 10 / 11 (64-bit)
- **GPU**: AMD Radeon GPU (Vulkan 対応 / VRAM 8GB以上推奨)
  - ※マザーボードの BIOS で **Resizable BAR (Smart Access Memory)** を有効化することを強く推奨します。（オンになっていないと速度が半分以下に落ちます）
- **ソフトウェア**:
  - **Python 3.10 以上**
  - **FFmpeg** (環境変数 `PATH` に通っていること)

## 使い方

### 1. 右クリックメニューから実行

1. `register_menu.bat` をダブルクリックして実行し、右クリックメニューに登録します。
2. 音声・動画ファイルを右クリックし、「Whisperで文字起こし」をクリックするだけで即座に実行されます。

### 2. バッチファイルから実行

1. `run_transcribe.bat` (英語の場合は `English/run_transcribe.bat`) をダブルクリックします。
2. `Original/` フォルダ内の対象ファイルが一括処理され、`Output/` フォルダに Markdown 形式 (`.md`) で自動出力されます。

### 3. コマンドラインから実行

```bash
# 通常実行 (デフォルトで 2分割並列処理が有効)
python transcribe_amd.py "path/to/video.mp4"

# 単一プロセスで実行する場合
python transcribe_amd.py "path/to/audio.mp3" --single
```

## 対応モデル

初回実行時に Hugging Face から自動ダウンロードされます。

- `large-v3-turbo` (推奨・標準): 軽量ながらLargeV3とほとんど同じ最高水準の日本語認識精度です。
  自分の好きなモデルを入れたい場合、Hugging Faceからダウンロードして `bin/Whisper-models/` フォルダに配置してください。
